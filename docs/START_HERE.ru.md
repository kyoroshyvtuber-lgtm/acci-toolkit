# Как дать это другому ИИ

1. Дай ему ссылку на репозиторий ACCI и доступ **только к нужному проекту**.
2. Убедись, что у него есть среда выполнения Linux с Python/Git и инструменты
   GitHub для кода, Actions, логов и артефактов. Обычного чата без инструментов
   или доступа только на чтение недостаточно.
3. Авторизуй GitHub через штатное приватное подключение или device login.
   Токены в чат и репозиторий не отправляй.
4. Передай задачу следующим сообщением.

## Готовое сообщение

```text
Используй https://github.com/kyoroshyvtuber-lgtm/acci-toolkit.
Прочитай README.md, AGENTS.md и docs/ACCESS.md.
Не полагайся на предыдущие чаты: всё необходимое должно быть в репозиториях.

Целевой проект: OWNER/REPO.
Задача: [что нужно сделать].

Проверь свои инструменты и доступ, установи ACCI, работай в отдельной
ветке acci/* и создай PR. Не сливай и не публикуй релизы без моего разрешения.
Запусти нужные тесты/сборку, изучи логи, скачай и проверь артефакты.
Если есть .acci/HANDOFF.md и .acci/handoff.json, восстанови состояние из них,
но проверь актуальный коммит и CI заново.
В конце дай ссылки на PR и проверенные сборки, перечисли ограничения,
подготовь handoff для следующего ИИ.
```

## Что переносится

Код инструментария, инструкции, CI-шаблоны, пример проекта и проверяемый
checkpoint задачи. Зависимости от Notion и конкретного поставщика модели нет.
Секреты, доступы, история чата и локальные артефакты автоматически не переносятся.

У разных ИИ разные инструменты, ограничения и качество работы.
ACCI делает процедуру воспроизводимой, но не гарантирует идентичный результат
любой модели и не выдаёт права самостоятельно.

## Приложения для iPhone, игры и работа без постоянных вопросов

- **Без Apple-ключей:** тесты XCTest/UI, отдельный симулятор, запуск, скриншот,
  архив приложения и результаты тестов. Нужен macOS runner GitHub, не твой Mac.
  Подробности и установка шаблона: [IOS.md](IOS.md).
- **Установка на настоящий iPhone:** нужны настройки конкретного приложения и
  подходящая подпись. Подготовлен отдельный выключенный workflow; сертификаты
  добавляй только в приватные Secrets GitHub, не в чат. Подпись не означает
  проверку на устройстве. TestFlight/App Store — отдельное разрешение и настройка.
- **Игры:** есть профили Godot/Unity и проверяемый headless-пример Godot.
  Экспорт проекта не равен готовой игре: [GAMES.md](GAMES.md).
- **Автономные небольшие задачи:** подготовлен режим «задача → модель → тесты →
  PR». По умолчанию он **выключен**. Нужно выбрать поставщика/модель, разрешённые
  исходники и расходы, добавить ключ приватно и явно включить два переключателя.
  Слияние, подпись и публикация ему не разрешены: [AUTONOMY.md](AUTONOMY.md).

Любой внешний ИИ с нужными инструментами по-прежнему может работать по
`AGENTS.md` без API-ключа модели в ACCI. Встроенный исполнитель — дополнительный
ограниченный режим, а не обязательное подключение к конкретной нейросети.
